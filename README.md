# Inferno IPTV – Updates

Dieses Repository enthält nur die fertigen Programmdateien von Inferno IPTV (keinen Quellcode).
Die Windows-App lädt neue Versionen automatisch von den [Releases](../../releases).

- **Windows:** `Inferno-IPTV-Setup-<Version>.exe` (aktualisiert sich danach selbst)
- **LG-Fernseher:** `Inferno-IPTV_<Version>.ipk` (Installation über den webOS Dev Manager)
